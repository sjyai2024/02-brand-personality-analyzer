## 근거
- Aaker (1997): 5차원 브랜드 개성.
- Vinyals-Mirabent et al. (2019): 공식 웹사이트 content unit 기반 내용분석.
- Pamuksuz, Yun & Humphreys (2021): 브랜드 생성 텍스트의 계산적 브랜드 개성 측정과 브랜드 단위 집계 논리.

## 본 연구의 수정 적용
자동 필터와 multilingual sentence embedding/cosine similarity, Relative Profile은 선행연구 모델의 복제가 아니라 석사논문 파일럿용 탐색적 조작화이다. 연구자가 최종 포함 여부를 직접 승인한다.
